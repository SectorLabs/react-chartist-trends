# react-chartist-trends

Fork of [fraserxu/react-chartist](https://github.com/fraserxu/react-chartist). React component for [@sector-labs/chartist-trends](https://github.com/SectorLabs/chartist-trends).

## Changes from upstream

* Switched from `chartist` to `@sector-labs/chartist-trends`
* Prefixed unsafe lifecycle methods with `UNSAFE_`
* Replaced the string ref with a callback ref, since string refs were removed in React 19

## Install

```
npm install @sector-labs/react-chartist-trends
```
